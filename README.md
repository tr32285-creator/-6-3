
# 🌷 My E-Portfolio

เว็บไซต์แฟ้มสะสมผลงานอิเล็กทรอนิกส์ (E-Portfolio) สำหรับรวบรวมประวัติส่วนตัว ประวัติการศึกษา ผลงาน และกิจกรรมต่าง ๆ

## 👩‍🎓 About Me

- **ชื่อ-นามสกุล:** นางสาวจิราภรณ์ สัตระ
- **มหาวิทยาลัย:** มหาวิทยาลัยธรรมศาสตร์
- **คณะ:** วิทยาศาสตร์และเทคโนโลยีการอาหาร

## ✨ Features

เว็บไซต์ประกอบด้วย 5 ส่วนหลัก ได้แก่

1. **Home** - หน้าแรกและแนะนำตัว
2. **About Me** - ประวัติส่วนตัวและข้อมูลเบื้องต้น
3. **Education** - ประวัติการศึกษา
4. **Portfolio** - ผลงานและเกียรติบัตร
5. **Activities** - กิจกรรมและประสบการณ์

## 🎨 Design

ออกแบบเว็บไซต์ด้วยโทนสีพาสเทลที่ให้ความรู้สึกอบอุ่นและสดใส

- สีส้มพีช (Pastel Orange)
- สีชมพูพาสเทล (Pastel Pink)
- สีเหลืองครีม (Pastel Yellow)
- สีครีม (Cream)

## 💻 Technologies Used

- HTML5 - ใช้สร้างโครงสร้างเว็บไซต์
- CSS3 - ใช้ตกแต่งและออกแบบเว็บไซต์
- JavaScript - ใช้เพิ่มลูกเล่นและการทำงานของเว็บไซต์
- Google Fonts - ใช้แสดงผลตัวอักษร Prompt
- Font Awesome - ใช้แสดงไอคอนต่าง ๆ

## 🚀 How to Use

1. ดาวน์โหลดหรือ Clone Repository
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์
3. สามารถแก้ไขข้อมูลส่วนตัวและเพิ่มรูปภาพผลงานได้ตามต้องการ
